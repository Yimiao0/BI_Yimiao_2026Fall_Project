# Collection rules (NSCLC, default template)

Collect stratum-arm-level data: one `included_arms` row per stratum-arm. The exclusion codes are defined in the exclusion rules below.

## 1. Decide what to exclude

Decide at the paper level first, then arm by arm.

### 1a. Paper level

Read the title, abstract and methods. Exclude the whole paper, without listing its arms, when either applies:

- **Wrong paper type** (paper-type codes): `TRIAL_MISMATCH`, `PROTOCOL_ONLY`, `NO_ARM_LEVEL_RESULTS`
- **Every arm out of scope:** every arm would be excluded under an out-of-scope code in 1b. Examples: a non-NSCLC study, a neoadjuvant trial, a chemoradiation trial.

Write one row to the `excluded` sheet with `exclusion_level` = "paper". If several codes apply, use a paper-type code before an out-of-scope code, and the lowest-numbered code within each group; name the others in `exclusion_evidence`.

A secondary analysis that reports arm-level baseline and outcomes (for example, a biomarker subset or long-term follow-up) is not excluded for its paper type. Fill it, and start `notes` with "SECONDARY ANALYSIS:".

If only some arms are out of scope (for example, the non-NSCLC cohorts of a basket trial), go on to 1b.

### 1b. Arm level

List every arm or cohort the paper reports. If an arm is split into strata (for example, treatment-naive vs pretreated), use one row per stratum. Use only strata that don't overlap and that have both baseline characteristics (age, sex, ECOG, smoking, stage; usually Table 1) and outcomes (ORR, median PFS). Don't make rows for outcome-only subgroups, such as those in a forest plot. If you split an arm into strata, don't also add a row for the whole arm. If the arm isn't split, use `stratum` = "all".

For each stratum-arm, check the out-of-scope codes: `NOT_NSCLC`, `SURGICAL`, `DEFINITIVE_CRT`, `INTRACRANIAL_ORR`, `ON_TREATMENT_SUBGROUP`.

- **If at least one applies:** write one row to the `excluded` sheet with `exclusion_level` = "arm". If several apply, use the lowest-numbered one.
- **If none applies:** fill its `included_arms` row (step 2).

If unsure, include the arm and start `notes` with "CHECK:" and your question.

**Overlap across papers:** if a paper is a subgroup, regional extension or follow-up of another trial, include the arm and start `notes` with "POSSIBLE OVERLAP: <parent trial>".

For excluded rows, fill only the `excluded` columns defined in the codebook.

## 2. Fill each included stratum-arm

Fill every `included_arms` column in the codebook. Leave `arm_id` blank; the app numbers the rows.

- Patient characteristics (sex, ECOG, smoking, stage, histology): enter counts. If only a percentage is given, count = round(% × `arm_sample_size`); say so in `notes`.
- ECOG: `ECOG_0_1 + ECOG_2 + ECOG_3 + ECOG_4 + ECOG_Unknown = arm_sample_size`. Always fill `ECOG_0_1`; fill `ECOG_0` and `ECOG_1` only if reported separately. Zubrod is the same scale as ECOG. Enter Karnofsky-only as `ECOG_Unknown` and say so in `notes`.
- Smoking: `Tobacco_Never + Tobacco_Ever + Tobacco_Unknown = arm_sample_size`; always fill these three. Fill `Tobacco_Current` and `Tobacco_Former` only if reported separately.
- Stage: all stage columns except `stage_IIIB_wet` add up to `arm_sample_size`. If eligibility fixes the stage (for example, "stage IV only"), fill it from eligibility and say so in `notes`.
- `ORR` and its CI limits are proportions from 0 to 1.
- Brain-metastasis cohorts: enter the systemic RECIST ORR, not the intracranial ORR, and start `notes` with "SPECIAL POPULATION: brain metastases".
- `mPFS_months`: days ÷ 30.4375, weeks ÷ 4.348. If median PFS is "not reached", leave it blank and say so in `notes`.
- `female_count`: if only the male count is given, `arm_sample_size` − male count.
- `median_age`: if only the mean is reported, enter it and write "MEAN age entered" in `notes`.

Before replying, check that the ECOG, smoking and stage sums each equal `arm_sample_size`. If the paper's own numbers don't add up, put the gap in the Unknown column and write "CHECK: <which sum>" in `notes`.

## 3. Write the notes

Start with any flags (`SECONDARY ANALYSIS:`, `SPECIAL POPULATION:`, `POSSIBLE OVERLAP:`, `CHECK:`), then:

1. **Sources:** the table or figure each group of values came from
2. **Population used** when denominators differ, for example ITT (all enrolled patients) for baseline but measurable-disease patients for ORR
3. **Anything unusual:** time to progression instead of PFS (in capitals), investigator vs central review, counts derived from percentages, mean age, unconfirmed responses

Example: "SECONDARY ANALYSIS: 5-year follow-up of the phase III trial. Table 1 (ITT n=186), Table 2. ORR = 22/186 by central review (BICR), confirmed responses. Female = 186 − 120 male. Stage IV by eligibility. MEAN age entered."

# Exclusion rules

The analysis population is **systemic therapy for advanced or metastatic NSCLC**. Exclude a paper or arm when its ORR or PFS can't fairly be compared with that population.

Use exactly one code. If more than one applies, use the lowest number:

Paper type (always paper-level):

1. `TRIAL_MISMATCH`: the paper reports a different trial than `nct_id`
2. `PROTOCOL_ONLY`: study protocol with no results
3. `NO_ARM_LEVEL_RESULTS`: no arm-level baseline, ORR or PFS

Out of scope (paper- or arm-level):

4. `NOT_NSCLC`: patients are not mostly NSCLC
5. `SURGICAL`: surgery is part of the planned treatment
6. `DEFINITIVE_CRT`: curative-intent chest radiation with chemotherapy
7. `INTRACRANIAL_ORR`: ORR counts brain lesions only
8. `ON_TREATMENT_SUBGROUP`: strata defined by an event during treatment
9. `OVERLAP`: patients already counted in another included arm (in this app: flag only, see rule 9)

A paper you couldn't get or read is not excluded; it goes to the `failed_papers` sheet.

For each excluded paper or arm, write one row to the `excluded` sheet, filling its columns as the codebook defines them.

Decide from the arm's planned treatment and population, not from words that appear in the paper.

---

## 1. TRIAL_MISMATCH

**Exclude:** papers that name a different NCT number, or report a different study than the trial in `nct_id`. Give the number or study it names in `exclusion_evidence`.

## 2. PROTOCOL_ONLY

**Exclude:** study protocols and design papers that report no results.

## 3. NO_ARM_LEVEL_RESULTS

**Exclude:** papers with no arm-level baseline, ORR or PFS, such as pooled analyses across trials, biomarker-only, pharmacogenetic, modelling, cost-effectiveness, quality-of-life and methods papers.

## 4. NOT_NSCLC

**Exclude:**
- Other-cancer cohorts of basket trials
- Small-cell lung cancer
- Brain metastases from primaries other than NSCLC
- Arms where NSCLC patients are a small minority

A trial registered as NSCLC can have a paper that reports only another cancer. Exclude it with this code; don't put it in `failed_papers`.

## 5. SURGICAL

**Exclude:** neoadjuvant, preoperative or perioperative therapy, and surgery alone.

## 6. DEFINITIVE_CRT

**Exclude:** curative-intent chest radiation given with chemotherapy, with or without another drug.

## 7. INTRACRANIAL_ORR

**Exclude:** arms whose only ORR is intracranial, for example RANO-BM or "CNS ORR".

## 8. ON_TREATMENT_SUBGROUP

**Exclude:** strata defined by something that happened after treatment started, such as side effects, early response, dose reductions or treatment duration.

## 9. OVERLAP

Papers are processed in separate batches, so you can't see which arms are already included. Don't exclude with this code. Instead, when a paper is any of the following, include its arms and start `notes` with "POSSIBLE OVERLAP: <parent trial name or NCT number>". A reviewer decides later.
- Regional subgroup of a global trial
- Regional extension study of a global trial
- Later phase of another trial's arms, such as the maintenance phase of a trial whose first-line arms are reported elsewhere
